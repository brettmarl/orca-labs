# Orca Labs LLC website

Static one-page site for [orca-labs.com](https://orca-labs.com), hosted on GitHub Pages.

No build step: edit `index.html` and push to `master`. GitHub Pages serves the repo root.

- `index.html` — the page (inline CSS)
- `OrcaLogo.svg` — logo
- `favicon.svg` — browser tab icon
- `CNAME` — custom domain for GitHub Pages
